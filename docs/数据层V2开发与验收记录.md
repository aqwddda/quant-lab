## Architecture

```text
src/data/
  schema.py / models.py
  normalize.py / adjustment.py / validation.py
  manifest.py / store.py / loader.py
  providers/
    base.py / yahoo.py / tushare.py / __init__.py

Provider → Immutable Source → Normalize → Validate
  → Versioned Bars / Adjustments / Actions / Reference
  → SHA-256 Manifest → Local Loader → Single-Asset Backtest
```

source 在 data/source，canonical 数据在 data/normalized，reference 在 data/reference，manifest 在 data/manifests。每个 dataset ID 有独立版本目录；没有可变 latest 指针。多个匹配版本明确报错，也可通过逐标的 dataset_id 映射选择多标的版本。

Provider 与 Strategy/Backtest 分离；本地 Loader 和回测不导入供应商 SDK、不下载缺失文件。src/data_loader.py 与 src/validation.py 的旧数据 API 共用新数据层实现。只有 source normalization 可以显式排序，Loader 验证冻结文件后才筛选，并对新组合的 long-format 结果排序。

## Price Semantics

| Basis | 公式/来源 |
| --- | --- |
| raw | Tushare daily 直接未复权；Yahoo source OHLC × 全部已知后续 split ratio 的乘积，显式反向还原其自带的拆股调整 |
| provider_adjusted | raw OHLC × (Yahoo Adj Close / reconstructed raw Close) |
| qfq | raw OHLC × cumulative factor / 请求结束日及之前的最新 factor；逐标的锚定，保留停牌日 factor，不使用结束日之后的数据 |
| hfq | raw OHLC × provider cumulative factor，保持绝对 provider scale |
| legacy_provider_adjusted | 直接使用原 V1 auto_adjust=True 冻结 OHLC |

Yahoo ratio 与 Tushare cumulative factor 有不同 factor_semantics，不能混用。缺少 bar-date factor 时不补齐。Source Data 表示供应商响应快照，不能据此认定它就是 raw price。Tushare volume 手→股、amount 千元→CNY；Yahoo 在 normalization 中对历史 volume/dividend 进行 inverse split scaling。浮点噪声与真实 fractional volume 分开处理。

与实施方案相比，特别澄清了 Yahoo auto_adjust=False 仍有拆股调整，以及 hfq 不按区间首日 factor 归一。这些由供应商口径/实际 SDK 源码确认，保证 raw 与 hfq 的定义准确。

## Known Limitations

- Yahoo source、action、reference 都是下载时快照，可能漏项/修订。Inverse split reconstruction 依赖供应商拆股/单位口径正确，不保证独立核验的历史 tape 或 point-in-time 可得性。
- Yahoo 当前 canonical normalization 限于已知 US exchange、USD、ETF/EQUITY；其他市场/资产明确拒绝，不能误标为 US。
- US 没有独立完整交易所日历，只检查 weekday 并在 manifest 明示；CN 使用供应商日历核验已有 bars，无法据此区分停牌和供应商漏 bar。
- Tushare 真实 API 权限/积分与返回质量尚未验收；6000 行响应上限明确报错，需要缩短请求区间。当前 Tushare 提供 A 股 equity daily，未实现 ETF/index 下载入口。
- Tushare corporate action event normalization 明确不支持；Yahoo 仅存 dividend/split。本期 Portfolio 不发放分红、不调整拆股 quantity。
- 调整价账户为 synthetic account；raw 账户只有 data pipeline smoke 含义，未处理 corporate action accounting。
- CN 未建模 T+1、涨跌停、停牌撮合、整手及完整税费，报告附带明确 smoke 限制。
- 回测仍为单资产 long/cash；多标的 Loader 不等于多资产 Portfolio。无实盘、ML、Paper Trading 或优化扩展。
- Source 或写入过程失败可能留下没有 manifest 的审计目录；重新下载必须使用新 dataset ID，不能覆盖原快照。
