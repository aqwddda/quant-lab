# 从当前代码理解 Quant Lab

本项目按数据、结构、策略、执行、账户、指标分离。先用人工 fixture 理解每一步，再使用来源明确的冻结数据。

## 1. 数据和时钟

`src/market/models.py` 中 Bar 是不可变的一根观测，timestamp 是 UTC bar_start，available_at 是该窗口完成时间。
日线供应商常提供 session 日期；normalization 显式转成 UTC 坐标，并记录午夜并非实际开盘的假设。分钟线来源必须指定时区和时间语义。
Loader 只读有 Manifest/SHA 的本地版本，绝不自动下载。

```python
from src.data.loader import load_dataset, iter_bars

frame = load_dataset('your_dataset_id', symbols=['AAPL'], timeframe='1d')
observations = tuple(iter_bars(frame))
```

## 2. Strategy 只决定目标

```python
from src.strategies.sma import SmaCrossStrategy
from src.strategies.base import StrategyContext

strategy = SmaCrossStrategy(20, 60)
for index, bar in enumerate(observations):
    decision = strategy.on_bar(StrategyContext(index, bar.available_at), bar)
    print(decision.target, decision.diagnostics)
```

None 为预热不可交易，0 为cash，1为long。策略不扣现金，不计算手续费，不模拟成交。
均线只读截至当前的close；等值目标为cash。

## 3. 下一开盘执行与账户

```python
from src.backtest.engine import BacktestEngine
from src.backtest.execution import Costs, EquityCashExecutionModel
from src.backtest.portfolio import EquityPortfolio

engine = BacktestEngine(
    SmaCrossStrategy(20, 60),
    EquityCashExecutionModel(Costs(0.0005, 0.0002)),
    EquityPortfolio(100000),
)
result = engine.run(observations)
```

Engine 先执行上一根已完成bar的目标，再在当前close估值并调用策略。T close生成目标，下一open成交。
买入滑点加价，卖出减价；现金扣trade_value+commission，slippage_cost已经含在price中，不能重复扣。
账户验证 equity=cash+市值，以及 equity−initial_cash=realized_pnl+unrealized_pnl。

## 4. 指标与审计

`src/backtest/metrics.py` 从完成账户计算收益、CAGR、风险、回撤与闭合交易统计。分钟线风险默认先取UTC每天最后的估值并重算日收益。
`python scripts/run_backtest.py --dataset-id <id>` 保存trade/equity/metrics和图。audit记录配置、Manifest、数据与源码SHA、环境和因果性检查。

## 5. Chan 是独立结构层

```python
from src.chan import ChanAnalyzer

analyzer = ChanAnalyzer()
analyzer.extend(observations)
print(analyzer.fractals, analyzer.confirmed_strokes, analyzer.current_stroke)
```

包含处理只看high/low；分型用严格三根合并K；笔要求中心合并索引差≥4。confirmed_at是确认信息可知时间，不是pivot坐标。
已确认笔不能随未来变化，最终 tentative 可以延伸。初始包含无方向默认报错。完整规则见[Chan文档](chan-core.md)。
